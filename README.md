# Avionics Altium Project Template
 When creating a new Altium project simply create a new repo on the APSS github selecting this project as the template:
 <img width="1050" height="824" alt="image" src="https://github.com/user-attachments/assets/05b2da81-b233-4f21-97b4-6cd7c568f7a2" />
 Then clone your new repo into your local machine and you can begin designing your PCB.

 ### Once you are done with your PCB and it is ready to be sent to PCBWay:
  - Generate the relevant outputs go to Projects < Settings < Output Job Files < Outputs.OutJob and open this file.
  - Underneath Output containers you will see 4 options: Documentation, PCB Fabrication, Bill of Materials, and Assembly.
  - Click on each one and hit "Generate Content" to generate the relevant content for each output. All these outputs should be in the Outjob-Outputs folder of the project.
  - Remove the outjob folder and its outputs from the gitignore and push the changes to github under a new branch.
  - For each new PCB print create a github release which can be found on the right side of the page as shown below.
  - Select your release branch as the Target for the release and publish the release.
